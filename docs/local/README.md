# Local private source metadata

本目录用于放置只对当前工作站有效、不得提交到公开 Git 的私人源文件定位信息。

## Agent 使用规则

- 权威 Excel 的本机定位记录为 `docs/local/private-source-workbook.md`；该文件由仓库 `.gitignore` 明确排除。
- 只有当用户明确要求调查真实源文件、按真实数据微调功能、最终对账或 cut-over 时，agent 才读取该定位记录并访问源文件。
- 访问前校验文件名和已审阅的 SHA-256；不匹配时立即停止，不能自行挑选相似文件。
- 原始工作簿始终只读。分析、重算、迁移和试运行必须使用副本、临时 staging 和候选数据库。
- 不把绝对私人路径、真实内容或分析输出复制到 tracked 文档、源码、fixture、日志、诊断包或提交信息。
- 若本机定位记录不存在，agent 必须请用户重新指定源文件，不得扫描私人目录猜测位置。

合成开发和自动化测试仍只使用 `fixtures/sanitized/`，本机定位记录的存在不构成读取真实账本的授权。

# LedgerKit 1.0.0-beta.1

This is the first open-source Beta candidate for the local-first LedgerKit desktop application. It provides a generic empty ledger and a strict normalized import path; it contains no private workbook, account, transaction, path, backup or reconciliation data.

## Included

- Five-entry bilingual Windows desktop UI: overview, activity, assets, data quality, settings/data.
- Decimal-based authoritative Rust Core for cash and investment events, immutable revisions/reversals, deterministic postings and rebuildable projections.
- As-of valuation and expense analysis with explicit incomplete/unvalued states.
- Strict staged Excel import with deterministic mapping, reconciliation and atomic candidate switch.
- Password-encrypted portable backups, verified restore, local/external retention, XLSX/CSV/reconciliation export and redacted diagnostics.
- Schema v7 forward migrations and manual upgrade/rollback workflow.

## Reproducible verification

```powershell
pwsh -NoProfile -File tools/check.ps1
pwsh -NoProfile -File tools/beta-performance.ps1
pwsh -NoProfile -File tools/build.ps1
```

The Windows x64 package is per-user NSIS and uses system WebView2. The installer is ignored and not committed; a local build writes `app/src-tauri/target/release/bundle/nsis/LedgerKit_1.0.0-beta.1_x64-setup.exe`. `tools/build.ps1` prints its size and SHA-256, and the measured candidate value is recorded in the performance report.

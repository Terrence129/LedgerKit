# 任务 12/14：概览、支出分析与数据质量 UI

你正在执行 LedgerKit 的资产概览、支出分析和数据质量 UI。遵循共同执行协议，确认 M5 后端和黄金测试已在 `main`，创建分支 `phase/m5-overview-expense-quality-ui`。

## 必读材料

- 开发计划书第 6.1、6.3、15.2–15.3 节
- ADR-0014、EXP/VAL 规则和 `ExpenseAnalysisQueryResult` 契约
- v1.3.0 支出分析的视觉意图与轻量预算

## 实现

1. “概览”包含“资产概览 / 支出分析”两个页内标签，不增加顶级导航。
2. 资产概览显示估值日、已估值净资产、未估值项目、机构/币种/现金/持仓构成、截至估值日 MTD 和数据质量待办。
3. 支出分析：
   - 首次进入把本地“今天”解析为明确的本月起止日。
   - 开始/结束日含首尾；非法范围关联字段报错并清空旧结果。
   - 显示总支出或“已折算支出小计”、全局 distinct 笔数、最大分类、退款/报销和未折算计数。
   - 渲染 Top 10 + 其他共最多 11 行的原生 HTML/CSS 横条。
   - 渲染同一结果的完整语义表格；金额、占比和笔数始终有文字。
   - 横条是重复视觉表达而非唯一交互；不增加 Canvas、D3、ECharts、Recharts 或其他图表运行时。
   - KPI/分类下钻生成 `DrilldownContext` 并进入活动页，返回后保留筛选。
   - 状态优先级固定为 invalid > incomplete/unvalued-only > no-valued-spend > normal。
4. UI 不解析后重新累加 DecimalString，不自行计算 KPI、Top 10、退款或桶归属。
5. 数据质量页展示异常、原因、定位、修复入口和状态，并能跳转到汇率/价格/映射或导入问题。
6. 新查询发出后丢弃旧请求迟到结果，避免日期快速切换显示过期数据。
7. 视觉使用现有设计 token、深蓝标题带、青绿色强调和紧凑层级；不得复制 Excel 辅助网格。

## 测试与验收

- 正常、缺 FX、只有未折算、零支出和非法日期。
- 11+ 分类、归档分类、未分类和系统费用桶。
- KPI、横条、语义表格和下钻完全同源。
- 键盘、`table/th/td/scope`、live region、高对比、reduced motion、200% 缩放和窄屏单列。
- 查询/筛选/下钻 P95 ≤200 ms，响应 ≤32 KiB。
- 支出页面新增生产依赖为 0，并达到计划书的资源增量预算。

# 任务 10/14：投资完整纵向切片

你正在执行 LedgerKit 的投资交易、持仓、收益和资产 UI。遵循共同执行协议，确认 M3 现金迁移已在 `main`，创建分支 `phase/m4-investments`。

## 必读材料

- ADR-0004、0005、0006、0012
- `docs/financial-rules.md` 的 INV、VAL、EVT 规则
- 投资、成本、价格、同日顺序、修订和投影黄金 fixture
- 开发计划书第 7–9、14 节

## 实现

1. 扩展 `EventCommand`：SecurityTrade(BUY/SELL)、Dividend、InvestmentExpense。
2. 买入成本包含买入手续费；卖出净收入扣除卖出手续费；两者不得再次计入独立投资费用。
3. 实现逐笔移动加权平均：
   - 卖出按卖出前平均成本结转并锁定已实现盈亏。
   - 全部卖清时结转全部剩余 carrying cost，强制 quantity=0、carrying_cost=0、average_cost=null。
   - 重新买入作为新开仓，不继承舍入残值。
   - 历史插入或修订从变更点按稳定 sequence 确定性重放。
4. 股息、预扣税、股息手续费和独立投资费用按 Accepted ADR 的唯一回报公式处理。
5. 持仓键严格为 `(portfolio_id,instrument_id)`；同一标的跨组合不得合并。
6. 禁止卖出超过持仓和 1.0 做空。
7. 覆盖默认结算账户时验证机构/币种并强制记录原因。
8. 实现可重建 HoldingProjection：数量、carrying cost、已实现交易盈亏、净股息、独立费用、未实现盈亏和总回报。
9. 活动页加入买入、卖出、股息、费用录入与详情；资产页完成组合、证券、价格历史、持仓列表和持仓详情。
10. 价格/FX as-of、陈旧价格、缺价格/FX 和未估值状态可从界面下钻解释。

## 测试与验收

- 买入、部分卖出、分批清仓、卖后再买。
- 同日稳定 sequence、历史插入和从变更点重放。
- 同标的跨组合隔离。
- 股息、预扣税、买卖费用、标的级/组合级独立费用。
- 负持仓阻断和结算账户覆盖留痕。
- 缺价格/FX、未来数据排除、陈旧警告。
- 修订/冲正后持仓、现金和收益重建一致。
- 全部投资黄金 fixture 和 canonical hash 通过。

通过后提交、合并并推送 `main`。

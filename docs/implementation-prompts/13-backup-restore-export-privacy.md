# 任务 13/14：备份恢复、导出与隐私硬化

你正在执行 LedgerKit 的备份恢复、导出、升级安全和隐私硬化。遵循共同执行协议，确认全部 P0 财务/UI 功能已在 `main`，创建分支 `phase/m6-data-safety-export`。

## 必读材料

- ADR-0008、0010 以及 ADR-0013 主题
- `docs/operations/backup-restore.md`
- `AGENTS.md` 隐私规则
- 开发计划书第 12、15、17、20、24 节

项目所有者已确认：P0 活库不使用 SQLCipher；P0 必须提供密码加密便携备份；自动更新和代码签名不是当前 Beta 完成条件。

## 实现

1. 完成并接受 ADR-0013，固定自动备份保留、设备丢失 RPO 声明条件和恢复密钥模型。
2. 一致性备份使用 SQLite Online Backup API、`VACUUM INTO` 或 M1 已验证方案，禁止复制正在写入的活库文件。
3. 备份包包含数据库、设置和版本化 manifest；P0 只保留数据库内的附件链接文本，不复制附件正文。
4. 按 ADR-0008 实现密码加密包：随机 salt/nonce/data key、认证加密、版本/KDF 参数和内容哈希；密码与密钥不写日志。
5. 实现 `create_backup`、`restore_backup`、`get_backup_status`：手动、migration 前、正常退出和外部目录每日备份；默认保留 7 个每日和 4 个每周版本。
6. 外部目录未配置或最近验证失败时持续显示“设备丢失未受保护”，不得宣称 24 小时 RPO。
7. 恢复先进入临时位置，验证认证、哈希、schema、integrity、外键和投影；再创建恢复前备份、关闭写入连接并原子切换。失败保留原活库。
8. 实现 `export_data`：标准化 XLSX、CSV 和对账报告；格式应在没有 LedgerKit 时仍可读取。
9. 文件选择只产生受限、一次性用户授权；Core 验证目的和路径，WebView 不获得任意路径能力。
10. 日志和诊断仅记录事件 ID、版本、错误类别和脱敏计数。导出/诊断前显示隐私提示。
11. 更新 migration、backup/restore、升级和回滚 runbook 的实际命令与兼容矩阵。

## 测试与验收

- 正确/错误密码、篡改、截断和未知格式/KDF。
- schema 过新、磁盘不足、目录失效、同步冲突和原子切换失败。
- 恢复失败不覆盖活库；恢复前备份可打开。
- 自动备份失败持续告警，成功状态来源可验证。
- XLSX/CSV 导出完整性和公式注入防护。
- 私人字段、金额、路径、口令和密钥不进入日志。
- 有效备份完整恢复流程 ≤10 分钟。

通过后提交、合并并推送 `main`。

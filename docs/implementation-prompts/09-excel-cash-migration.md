# 任务 09/14：Excel 现金迁移

你正在执行 LedgerKit 的 Excel staging、dry-run 和现金子集迁移。遵循共同执行协议，确认 M2 现金纵切已在 `main`，创建分支 `phase/m3-excel-cash`。

## 必读材料

- `docs/operations/migration.md`
- ADR-0007、0011 与全部 MIG 规则
- 脱敏 fixture 规则和开发计划书第 13–14 节

禁止读取、搜索或处理真实 `多币种个人账本v1.3.0.xlsx`；只使用程序生成的合成文件。

## 实现

1. 使用 ADR-0007 选定库，只读解析已知模板中的设置、机构、账户、分类、汇率、收支、调拨和换汇表。
2. 维护确定性合成 XLSX fixture，覆盖公式文本、缓存值、坏行、重复、分类方向错误、缺 FX 和同字节重跑。
3. ImportBatch/ImportRow staging 保存工作表、行号、原始文本、公式文本、缓存值、内容哈希、导入器版本和目标 schema 版本。
4. 实现 `analyze_import`：
   - 计算文件哈希、识别模板版本。
   - 区分硬编码输入、带公式输入、派生公式、状态和展示字段。
   - 执行字段、引用、重复、公式缓存、币种、分类、FX 和 cut-over 校验。
   - 每个问题定位到工作表和 Excel 行号。
   - 生成拟议事件、posting、账户原币余额和规范差异报告。
   - 不写正式账本。
5. 实现 `commit_import`：
   - 只接受用户已确认且无 blocker 的 batch。
   - 写入新的候选数据库，不直接改活库。
   - 单事务提交并重建投影。
   - 对账、完整性和备份验证通过后原子切换。
   - 失败保留旧活库并隔离/丢弃候选。
6. 同一字节文件、相同 importer/schema 重跑幂等；修改或另存文件必须成为新候选，禁止 merge 到已过账账本。
7. 首次导入 UI：文件选择、进度、映射、问题清单、对账摘要、确认和失败恢复。
8. 解析在 worker/平台线程执行，UI 不冻结。

## 测试与验收

- 正常现金导入及现金子集对账。
- 缺缓存公式、坏引用、重复、方向错误、缺 FX 和非法日期。
- 同字节重跑幂等；修改文件不增量合并。
- 解析/提交中途失败不污染活库。
- 日志只包含定位、版本和错误类别，不复制私人值。
- 当前规模导入 ≤10 秒，UI 保持响应。

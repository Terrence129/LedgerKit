# ADR-0005：证券移动加权平均与历史重放

> 状态：Accepted
>
> 日期：2026-09-02
>
> 决策者：项目所有者
>
> 授权：项目所有者在 M0 实现提示中明确接受逐笔移动加权平均、清仓归零和重新开仓语义，并授权本 ADR 直接设为 Accepted。
>
> 关联规则/里程碑：M0、INV-001 至 INV-008

## 背景

Excel 的累计买入平均近似会让“买入、部分卖出、再次买入”中的新买入改变历史卖出成本。LedgerKit 需要在卖出时锁定已实现盈亏，同时保持个人账本可理解、可迁移和可确定性重放。

## 决策驱动因素

- 已实现盈亏不被未来交易改写
- 清仓无 Decimal 残值，重新开仓不继承旧成本
- 按组合隔离同一标的的数量、成本和回报
- 迁移时能解释与 Excel 累计平均的差异

## 方案

### 方案 A：逐笔移动加权平均

每个 `(portfolio_id, instrument_id)` 独立维护数量和 carrying cost；买入更新成本，卖出按卖出前平均成本结转并锁定盈亏。

### 方案 B：Excel 累计买入平均

迁移对数容易，但未来买入可能重算过去卖出成本，不适合作为权威引擎。

### 方案 C：FIFO 或显式 lot

适合部分税务场景，但导入、数据模型和 UI 复杂度超出 1.0。

## 决策

接受方案 A：

- 成本和回报的权威键为 `(portfolio_id, instrument_id)`；同一标的跨组合绝不合并。
- 买入成本等于 `quantity × unit_price + trade_fee`。新 carrying cost 为旧 carrying cost 加本次买入成本；平均成本只作为 `carrying_cost / quantity` 的派生值。
- 部分卖出按卖出前平均成本结转，卖出净收入等于 `quantity × unit_price - trade_fee`，本次已实现交易盈亏等于净收入减结转成本。结转结果遵循 ADR-0004 的 scale 18 边界。
- 当卖出数量精确等于卖出前数量时，结转全部剩余 carrying cost，并强制 `quantity="0"`、`carrying_cost="0"`、`average_cost=null`。
- 卖出超过可用数量返回 `NEGATIVE_HOLDING_NOT_ALLOWED`；1.0 不支持做空。
- 清仓后再次买入以新买入成本独立开仓，不继承舍入残值，不改变已过账卖出的成本或已实现盈亏。
- 买入费只进入成本；卖出费只减少净卖出收入；两者不再计为独立投资费用。净股息为股息总额减预扣税和股息手续费。
- 投资总回报唯一公式为：`已实现交易盈亏 + 净股息 - 独立投资费用 + 未实现盈亏`。组合级独立费用首版不自动摊派。
- 修订、冲正或历史插入从受影响的 `(portfolio, instrument)` 变更点按稳定 sequence 重放，并显示受影响期间。旧 watermark 的导出仍可按旧事件集复现。
- Excel 累计平均只用于迁移差异桥，不作为 posting 或投影算法；本功能不宣称满足税务申报规则。

## 后果

- 正面影响：已实现盈亏稳定、清仓精确、算法易于解释和回放。
- 负面影响：与 Excel 或某些税务报表可能存在预期差异；需要明确差异桥。
- 数据迁移影响：完整历史可重放；cut-over 必须提供数量、carrying cost 和分项历史业绩。
- 测试与运维影响：必须覆盖部分卖出、多次卖出、精确清仓、重开、费用、同日顺序、跨组合和负持仓。

## 反转条件

若未来范围加入税务 lot、FIFO 或指定批次，必须新增 lot 源事实和迁移方案，以新 ADR 定义是仅影响未来还是重算历史。不能静默重解释既有已实现盈亏。

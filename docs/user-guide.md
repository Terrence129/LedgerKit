# LedgerKit Beta 用户手册

> 适用于 `1.0.0-beta.1`。LedgerKit 是本地优先的开源个人账本；默认不需要账号、服务器或网络。

## 安装与首次使用

1. 仅从项目发布渠道取得 Windows x64 per-user 安装包，并按发布说明核对 SHA-256。当前 Beta 未签名，Windows 可能显示未知发布者提示。
2. LedgerKit 使用系统已有的 WebView2；若系统缺少运行时，请先通过 Windows 或 Microsoft 官方安装方式补齐。
3. 首次启动可新建空账本，选择三字母本位币；也可从规范化迁移工作簿进入只读分析。创建首笔业务数据后，本位币会冻结。
4. 应用界面只支持 `zh-CN` 和 `en-US`。切换语言只改变资源文本，不改变名称、备注、业务 ID、财务结果或 canonical hash。

## 五个入口

- 总览：查看估值净资产、现金、持仓、本月至今支出和数据质量待办；支出分析是总览内的次级标签。
- 流水：预览并过账收入、支出、调整、调拨、换汇和投资事件；已过账事件只能修订或冲正。
- 资产：按明确日期查看持仓、成本、价格/汇率证据与投资回报。
- 数据质量：定位缺失汇率、缺失或陈旧价格、负持仓和引用问题，并跳转到修复入口。
- 设置与数据：维护主数据与市场数据，执行导入、加密备份、恢复和独立导出。

## 日常记账

在“流水”填写事件后先选择“预览权威影响”。预览由 Rust Core 生成金额、posting、汇率解析与质量问题；确认后才在同一 SQLite transaction 中保存事实、posting 和投影水位。金额、数量、价格和汇率均使用十进制定点规则，不用二进制浮点。

缺少必要汇率或价格时，LedgerKit 显示“未折算/未估值”及质量问题，不会静默使用零或 1:1。退款、报销、普通手续费、换汇手续费和投资费用遵循各自口径；不要用负支出模拟退款。

## 更正历史

打开流水详情后使用“修订”创建取代事件，或使用“冲正”创建相反影响。旧事件、旧 posting 和审计链继续保留。不要直接编辑数据库，也不要删除 WAL/SHM 文件。

## 备份、恢复与导出

至少设置一个仓库之外、设备之外的外部备份目录，并使用不少于 12 字符的独立密码创建 `.lkbackup`。密码遗失无法恢复。恢复总是在候选位置验证，已有活库会先生成恢复前快照；任一步失败都不会替换当前活库。完整操作与兼容矩阵见 [`operations/backup-restore.md`](operations/backup-restore.md)。

XLSX、CSV 和 reconciliation 导出可能包含完整私人字段；diagnostics 只包含稳定技术状态和表计数。导出文件同样不得提交到公开仓库。

## 更新、卸载与故障处理

Beta 不自动检查或下载更新。升级前创建并验证便携备份，退出应用，再运行新版安装包；详见 [`operations/upgrade-rollback.md`](operations/upgrade-rollback.md)。卸载应用只删除安装目录，不应把卸载当作删除用户账本的手段。

若启动被阻断，先记录界面显示的稳定错误码和应用/schema 版本，不要复制私人行内容或路径到公开 issue。保留原账本与备份，使用 diagnostics 导出提供无私人字段的诊断证据。
